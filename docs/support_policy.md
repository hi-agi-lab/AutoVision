# AutoVision 支持政策

> 政策草案；企业 SLA 以合同为准。

## 社区支持

- 渠道：公开仓库 Issues / Discussions。
- 工作日 **48 小时内**首次响应（尽力而为，不含修复承诺）。
- 报告需附：版本、模型键、后端、硬件、复现命令、日志/最小样例。
- 不处理：受限许可权重的直链分发、未授权数据、绕过许可的请求。

## 企业支持（合同项）

| 级别 | 定义 | 首次响应 | 目标恢复 |
|---|---|---|---|
| P1 | 生产不可用 / 数据损坏 / 安全事件 | 4 小时（7×24） | 24 小时 |
| P2 | 关键功能受损，有规避方案 | 1 个工作日 | 5 个工作日 |
| P3 | 一般缺陷 / 使用咨询 | 3 个工作日 | 下个 PATCH |

- 渠道：私有工单 + 指定联系人；可含私有构建、部署协助、版本锁定。
- 支持范围：框架代码、官方模型卡/权重、导出与部署门禁、文档所述后端。
- 不含：客户数据质量、第三方硬件 SDK 缺陷、未在支持矩阵中的组合。
- 安全报告：私下邮件/工单，确认后按 LTS 政策处理。

## 支持矩阵

每个 LTS 发布页登记：

- Python / PyTorch / CUDA / TensorRT / OpenVINO 版本；
- 通过 parity 的后端（torch / ONNX Runtime / TensorRT / OpenVINO）；
- 已验证硬件（GPU 型号、CPU、边缘平台）；
- 已知限制（链接到 [已知限制](known_limits.md)）。

## 版本与升级

- 企业可锁定 LTS 版本；补丁按 LTS 政策 backport。
- 升级前用 `compliance-report` 归档依赖/模型/数据证据，用
  `verify_end_to_end_parity` 复验目标后端。
- 破坏性变更遵循 [LTS 政策](lts_policy.md) 与弃用窗口。
